# IT-GURU Products Admin

Панель управления каталогом товаров, выполненная в рамках тестового задания.  
Приложение представляет собой полноценную админ-панель с авторизацией, интерактивной таблицей данных и возможностью локального менеджмента продуктов.

## 🚀 Технологический стек

- **Core:** React 19, TypeScript, Vite
- **Routing:** React Router (с кастомными роут-гардами Protected/Public)
- **State Management:** Zustand (управление сессиями и токенами)
- **Forms & Validation:** React Hook Form + Zod (строгая типизация форм)
- **Network:** Axios (клиент с обработкой серверных ошибок)
- **Styling:** CSS Modules (изолированные стили компонентов)
- **UI Feedback:** react-hot-toast, кастомные лоадеры

---

## 📐 Архитектура проекта

Проект спроектирован по методологии **FSD (Feature-Sliced Design)**, что обеспечивает высокую масштабируемость и слабую связанность модулей:
- `app/` — инициализация приложения, глобальные провайдеры и роутинг.
- `pages/` — композиция страниц (Login, Products).
- `widgets/` — крупные интерактивные узлы (LoginForm, ProductsTable).
- `features/` — самостоятельные фичи (авторизация через API, добавление товара).
- `entities/` — бизнес-сущности приложения (сессия пользователя, модель продукта).
- `shared/` — переиспользуемые UI-компоненты, утилиты и конфигурации.

## 🛠️ Реализованный функционал

### 🔐 Авторизация
- **Валидация:** Клиентская проверка полей на лету с помощью Zod.
- **Гибкая сессия (Remember Me):** 
  - Данные сохраняются в `localStorage`, если чекбокс активен.
  - Данные сохраняются в `sessionStorage`, если чекбокс выключен.
- **Безопасность роутов:** Полная изоляция приватной зоны. Без токена доступ к `/products` закрыт; авторизованных пользователей автоматически перенаправляет с `/login` на каталог.
- **UX:** Интеграция всплывающих уведомлений (toast) на системные и серверные ошибки.

### 📦 Таблица товаров (Каталог)
- **Синхронизация с URL:** Состояние поиска и выбранной сортировки кодируется в URL-параметры. Ссылкой на отфильтрованную таблицу можно поделиться.
- **UI/UX:** Наличие плавного прогресс-бара во время запросов к API. Визуальный маркер для товаров с низким рейтингом (рейтинг < 3 подсвечивается красным).
- **Данные:** Интеграция с DummyJSON API + клиентская дофильтрация.

### ➕ Дополнение ассортимента
- Модальное окно для создания новой карточки товара (Наименование, Цена, Вендор, Артикул).
- Оптимистичное локальное добавление новой позиции в UI без выполнения мутаций на демонстрационном API.

## 💻 Установка и запуск

### Требования к окружению
- **Node.js**: >= 20.x
- **Пакетный менеджер**: npm

### Локальный запуск
```bash
# 1. Клонировать репозиторий и установить зависимости
npm install

# 2. Запустить сервер для разработки
npm run dev -- --host 127.0.0.1 --port 4273
```

После запуска приложение доступно по адресу:  
🔗 **[http://127.0.0.1:4273/login](http://127.0.0.1:4273/login)**

### Тестовые доступы (DummyJSON)
- **Логин:** `emilys`
- **Пароль:** `emilyspass`

> 💡 **Примечание для ревьюера:** В dev-режиме интегрирован локальный fallback-механизм проверки данных `emilys / emilyspass`. Если внешний сервис DummyJSON Auth будет временно недоступен или заблокирован, демонстрация проекта не прервется.
